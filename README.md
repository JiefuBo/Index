# James Bo — Personal GitHub Pages Site

A lightweight static personal site for **James Bo / JiefuBo**, inspired by the general layout idea of TinkerREN's personal homepage while using original styling and content.

## Sections

- Hero / profile
- About
- Featured GitHub projects
- Skills & interests
- Contact

## Deploy with GitHub Pages

1. Create a public repository named `JiefuBo.github.io`.
2. Upload `index.html` and `style.css` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save. Your site will normally be available at:

   `https://jiefubo.github.io`

## Customise

Edit `index.html` to change:

- Your display name
- About text
- Email
- Project descriptions
- Social links
- Skills

The avatar currently loads from your GitHub profile automatically.
